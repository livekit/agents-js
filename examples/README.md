# Examples

The [`src`](./src/) directory contains runnable TypeScript agents. Build the workspace before
running an example.

## Homepage

The agents behind the livekit.io homepage demos are in [`src/homepage`](./src/homepage/):

- [`card-auth`](./src/homepage/card-auth/): Kestrel Bank card verification.
- [`frontdesk`](./src/homepage/frontdesk/): Juniper Health appointment scheduling.
- [`restaurant-ordering`](./src/homepage/restaurant-ordering/): Zappi's Pizzeria ordering.
- [`vehicle-service`](./src/homepage/vehicle-service/): Bayside BMW service scheduling.
